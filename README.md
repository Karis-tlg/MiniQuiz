# MiniQuiz

MiniQuiz is a small educational project I am building as a university student.

The goal is simple. I want to make it easier for students to create quizzes, practice what they have learned, and review their results in one place.

## Current features

MiniQuiz currently supports user accounts, quiz creation and editing, image support, quiz randomization, submissions, results, and learning history.

The project is still being developed and some parts may change over time.

## What I want to build next

I want MiniQuiz to be able to understand study materials such as PDF files, lecture notes, images, and scanned documents.

The idea is to use OCR and AI to extract useful content from those documents and help students generate quizzes automatically.

I also want to improve recognition for Vietnamese educational documents, especially files that contain tables, formulas, images, and scanned pages.

## Tech stack

Frontend uses TypeScript, Lit, Vite and Tailwind CSS.

Backend uses Python and FastAPI.

MongoDB is used for data storage.

## Project status

MiniQuiz is a personal student project and is still in active development.

I am building it to learn more about web development, backend systems, document processing, and AI while creating something that can be useful for other students.
